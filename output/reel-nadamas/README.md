# Reel Nadamas

MP4 vertical 1080 × 1920, 30 fps, duración exacta de 8 segundos. H.264 + AAC, con sonidos de toque y confirmación.

Demostración ilustrativa con pantallas recreadas: solicitud del alumno, envío de comprobante, confirmación del pago por el coordinador, aceptación de clase y calendario actualizado. No se realizaron operaciones reales.

Se usan la fotografía real y el archivo original del logo proporcionados por Zarza.

- `nadamas-reel-8s.mp4`: video final.
- `storyboard.jpg`: vista de doce momentos.
- `preview.html`: composición animada autocontenida.
- `render.cjs`: fuente del render; ejecutar desde este proyecto con `node output/reel-nadamas/render.cjs`. Requiere Playwright, FFmpeg y los archivos originales en las rutas indicadas.
- `audio.wav`: efectos originales generados para el reel.
